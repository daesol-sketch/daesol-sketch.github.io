🔔 관리자에게 오는 알림

⚠️ 담당자 신고접수 미확인
배정된 직원이 3분 넘게 확인하지 않으면 관리자에게 옵니다. 직원이 알림을 못 보고 있다는 뜻이니 전화로 신고 내용을 전달해주세요.
📞 전화 착신 PC만
회사 전화로 전화가 오면 관리자 PC에 바로 표시됩니다.
① 등록된 현장 번호 → 📞 전화 착신 · [현장명] [호기]
② 등록된 직원 번호 → 📞 전화 착신 · 직원 [직급] [이름]
③ 미등록 번호 → 📞 전화 착신 · 미등록 번호 (010-XXXX-XXXX)
알림을 누르면 신고 접수 화면으로 이동하고 건물명·전화번호가 자동으로 들어갑니다.
전화 착신 알림은 PC에서만 받습니다. 폰으로 앱에 들어간 뒤 PC 알림이 안 오면, PC에서 앱을 한 번 새로고침해주세요.

🔧 신고 접수 · 배정

🔧 신고 접수 & 담당자 배정

  • 고장 관리 → 신고 접수에서 담당팀·담당자를 골라 접수하면 담당자에게 바로 알림이 갑니다.
  • 담당자가 3분 넘게 확인하지 않으면 미확인 알림이 옵니다 → 전화로 전달해주세요.
  • 처리중인 신고는 상세 화면에서 처리담당자를 변경할 수 있습니다.
  • 신고 접수 내용(시간·유형·내용)은 상세 화면 "✏️ 접수 정보 수정"에서 고칩니다.

🏢 관리현장 관리

🏢 관리현장 관리

  • + 현장 추가, 목록의 수정 / 삭제로 현장과 호기를 관리합니다.
  • 여러 현장을 체크한 뒤 계약 연장 1년 / 2년 / 3년으로 한 번에 연장할 수 있습니다.
  • 📥 엑셀로 현재 검색·필터 결과를 내려받습니다.
  • 🔄 전체 정보 갱신(마스터)은 전체 현장의 검사 정보를 한 번에 새로 받습니다. 시간이 오래 걸립니다.

👤 인사 · 휴일 관리

👤 인사 관리 (계정)

  • ☰ 메뉴 → 인사 관리 → + 계정 추가
  • 아이디, 비밀번호, 계정 유형(직원 / 관리자 / 마스터), 팀·직급·전화번호 입력
  • 목록에서 비밀번호 초기화, 삭제를 할 수 있습니다. 삭제하면 그 직원 기기의 로그인도 함께 풀립니다.
전화번호를 등록하면 해당 직원이 회사로 전화할 때 알림에 이름이 표시됩니다.

📅 휴일 관리

  • 날짜와 휴일명(예: 개천절, 단체연차) 입력 → + 추가
등록한 휴일은 고장 담당자 현황에서 주말·휴일 당직으로 처리됩니다.

📄 계약서 보관함

📄 계약서 보관함

  • + TKE 업로드 / + 대솔이엘 업로드로 계약서 PDF를 올립니다. (여러 개 한 번에 가능)
  • 파일명·메모로 검색하고, 여러 개를 골라 한 번에 삭제할 수 있습니다.

📊 통계 · 직원 알림 점검

📊 통계

  • 📈 접속 통계 — 오늘·이번주·이번달 접속자, 팀별 사용률, 직원별 접속 일수, 미접속 직원
  • 📋 메뉴 이용 — 어떤 메뉴를 많이 쓰는지, 직원별 자주 쓰는 메뉴
  • 🔧 고장 통계 — 월별 접수 추이, 유형별·현장별·담당자별 건수, 평균 처리시간, 엑셀

🔔 직원 알림 점검

  • ☰ 메뉴 → 알림 테스트 아래 👥 직원별 현황에서 직원마다 알림이 잘 도착했는지 볼 수 있습니다.
  • 테스트를 안 한 직원이 위쪽에 표시됩니다.
