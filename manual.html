📲 앱 설치 방법

📱 아이폰 (iOS)

  • Safari 브라우저로 앱 주소 접속
  • 하단 공유 버튼(□↑) 탭
  • "홈 화면에 추가" 선택
  • "추가" 버튼 탭 → 홈 화면에 아이콘 생성
🚨 아이폰은 홈 화면에 추가한 아이콘으로 실행해야만 알림이 옵니다. Safari 창에서 그냥 열면 알림을 받을 수 없습니다.

🤖 안드로이드

  • 크롬 브라우저로 앱 주소 접속
  • "앱 설치" 배너 또는 메뉴(⋮) → "홈 화면에 추가" 선택
  • "설치" 버튼 탭 → 홈 화면에 아이콘 생성

💻 PC (윈도우 / Mac)

  • 크롬 브라우저로 앱 주소 접속
  • 주소창 우측 설치 아이콘(⊕) 클릭 또는 메뉴(⋮) → "대솔이엘 설치"
  • "설치" 클릭 → 바탕화면 앱으로 실행 가능

🔐 로그인 · 내 정보

🔔 알림 설정

🚨 알림을 허용해야 고장 신고 배정 알림을 받을 수 있습니다. 반드시 허용해주세요!

알림 허용 방법

  • 로그인 후 알림 허용 팝업이 뜨면 "허용" 클릭
  • 팝업이 안 뜬 경우 → 브라우저 주소창 자물쇠 아이콘 → 알림 → 허용으로 변경

🤖 안드로이드 — 알림이 늦거나 소리가 안 들릴 때

  • 배터리 제한 풀기: 설정 → 애플리케이션 → Chrome → 배터리 → "제한 없음"
  • 알림 볼륨 올리기: 설정 → 소리 및 진동 → 음량 → 알림 음량을 올려주세요. (음악·동영상 음량과 따로입니다)
  • 진동도 받고 싶다면: 설정 → 소리 및 진동 → "소리 모드에서 진동" 켜기
⚠️ 배터리 설정을 안 하면 화면이 꺼진 상태에서 알림이 늦게 오거나 누락될 수 있습니다.
※ 이 앱은 카카오톡 같은 설치형 앱이 아니라서, 알림 소리 종류나 크기는 휴대폰 설정으로만 바꿀 수 있습니다.

📱 아이폰 알림 설정

  • 반드시 홈 화면에 추가한 아이콘으로 앱 실행
  • 설정 → 알림 → 대솔이엘(또는 Safari) → 알림 허용 켜기
⚠️ iOS 16.4 이상에서만 알림을 지원합니다.

🔔 알림 테스트 — 내 폰에 알림이 잘 오는지 확인하기

  • ☰ 메뉴 → 알림 테스트
  • 1분 후 / 3분 후 / 5분 후 중 하나를 누릅니다. (제대로 확인하려면 5분 권장)
  • 버튼을 누른 뒤 앱을 닫고 화면을 끄세요.
  • 정한 시간이 지나 알림이 오면 정상입니다. 앱을 다시 열면 내 최근 결과에 도착 여부와 걸린 시간이 표시됩니다.
알림이 안 오면 위의 배터리·알림 설정을 다시 확인하고 테스트해 보세요.

📋 알림 종류

🕐 고장 담당자 현황 (매일 오전 08:30에 초기화)

화면 구성

  • 맨 위 — 오늘 날짜·시각과 지금 시간대(☀️ 주간 / 🌙 평일 숙직 / 📅 주말·휴일 당직)
  • 내 당직 등록 — 오늘 당직 등록·해제 버튼 (오늘이 평일이면 주간·평일숙직 버튼, 주말·휴일이면 주말 버튼만 보입니다)
  • 📅 내일 사전등록 — 내일 당직을 미리 등록하는 보라색 버튼
  • 오늘 당직 현황 — 자리별로 등록된 사람 이름. 비어 있으면 "미등록"
  • 📅 내일(N일) 사전등록 예정 — 내일 미리 등록된 사람 (보라색)

휴일 관리에 등록된 날(공휴일·단체연차)은 평일이어도 주말·휴일 당직으로 바뀝니다.

내 당직 등록 / 해제

  • 내 자리 버튼을 누르면 "✅ 등록 완료!"가 뜨고, 버튼이 빨간색 "○○ 해제"로 바뀝니다.
  • 빨간 해제 버튼을 누르면 등록이 풀립니다.
  • 같은 시간대에는 한 자리만 등록할 수 있습니다. (예: 풍동숙직과 파주대기 동시 등록 불가)
  • 자리가 꽉 찼으면 "이미 정원이 찼습니다"가 뜹니다.
당직 등록은 직원 계정만 할 수 있습니다. 계정에 팀이 없으면 등록이 안 되니 관리자에게 팀 설정을 요청하세요.

📅 내일 사전등록

  • 내일 당직을 오늘 미리 등록해 둘 수 있습니다. 내일 오전 8:30부터 그대로 적용됩니다.
  • 내일이 주말·휴일이면 풍동숙직 / 파주숙직 버튼만, 평일이면 주간 / 풍동숙직 / 파주대기 버튼이 나옵니다.
  • 등록·해제 방법은 오늘 당직과 같습니다.
"오늘·내일"은 오전 8:30 기준입니다. 예를 들어 새벽 2시에 누르는 "내일 사전등록"은 그날 아침 8:30부터 적용됩니다.

고장 신고 담당자 목록과의 관계

  • 평일 주간: 신고 접수 시 담당자 목록에는 그 팀 소속 직원 전원이 나옵니다.
  • 평일 숙직·주말·휴일: 여기 당직 등록한 사람만 담당자 목록에 나옵니다. 당직이면 반드시 등록해주세요.

🔧 고장 관리

고장 관리 화면 구성

📋 신고 접수새 고장 신고 등록
📂 신고 내역진행 중인 신고(배치완료·처리중) 목록. 나의 처리중 버튼으로 내 것만 보기
✅ 고장처리내역완료된 신고. 오늘/이번주/이번달/전체, 유형 필터, 📥 엑셀
🔁 반복고장현황같은 호기에서 고장이 여러 번 난 곳. 기간·횟수·유형 필터, 📥 엑셀

📋 신고 접수하기

  • 접수 일시 — 기본은 지금 시각. 🕐 현재 시간 버튼으로 다시 맞출 수 있습니다.
  • 건물명 — 몇 글자 입력하면 목록이 나옵니다. 목록에서 골라야 점검자·호기 정보가 연결됩니다.
  • 호기 · 고장 유형 선택
  • 담당팀 → 담당자 선택 — 평일 주간은 그 팀 직원 전원, 숙직·주말·휴일은 당직 등록한 사람만 나옵니다. 아무도 없으면 "⚠️ 현재 등록된 당직자가 없습니다"가 뜹니다.
  • 접수자 이름, 신고자 연락처, 상세 내용 입력 → ✅ 신고 접수하기
담당자를 고르면 그 직원에게 바로 배정 알림이 갑니다. 담당팀을 기타로 접수하면 담당자 없이 등록되고, 직원이 직접 배치를 눌러 가져갈 수 있습니다.

✅ 배치 / 🔄 재배치 버튼

  • 신고 내역의 각 신고 카드에 표시됩니다.
  • 배치 — 담당자가 없는 신고를 내가 맡을 때
  • 재배치 — 이미 담당자가 있는 신고를 내가 넘겨받을 때
📍 휴대폰에서는 신고 카드 오른쪽 위 티맵 아이콘을 누르면 그 현장으로 바로 길안내가 됩니다.

📝 처리내용 입력 & 완료

  • 신고 내역에서 해당 신고를 누릅니다.
  • 처리 정보에 입력합니다: 도착시간, 처리일시, 처리/상세내역
  • 부품을 바꿨으면 "부품 교체 있음" 체크
  • 갇힘정지였다면 🆘 구출 정보(구출자: 119 / 유지관리업체 / 관리주체 / 해당없음, 구출시간)도 입력
  • 처리 상태를 완료로 바꾸고 저장
⏰ 처리중 상태로 8시간이 지나도록 완료하지 않으면 피드백 미처리 알림이 30분마다 옵니다.

🏢 관리현장

🔍 현장 찾기

  • 검색창에 현장명 · 점검자 · 승강기번호 · 전화번호 · 주소 중 아무거나 입력
  • 띄어쓰기는 신경 쓰지 않아도 됩니다. (예: "삼송로138" → 삼송로 138-1)
  • 전화번호·승강기번호는 "-" 없이 입력해도 찾아집니다.
  • 위쪽 필터로 보기 범위를 바꿀 수 있습니다: ✅ 보수현장(기본) / 전체 / ⚠️ 계약만료 / 🔍 검사만료 / 🏗️ 하자 / 🆓 무상 / ❌ 상실 / 🧾 계산서발행용, 그리고 팀별 보기
검사만료가 30일 이내인 현장은 주황색, 이미 만료된 현장은 빨간색으로 표시됩니다.

✏️ 현장 정보 수정

  • 현장 목록 오른쪽 초록색 "정보 수정" 버튼
  • 고칠 수 있는 항목: 주점검자 · 보조점검자1 · 보조점검자2 · 비상통화장치 번호 · 비고
  • 비상통화장치 번호는 회선 추가로 여러 개 넣을 수 있습니다. "2호기: 010-1234-5678"처럼 호기를 앞에 쓰면 전화 착신 알림에 호기까지 표시됩니다.

🟠 호기 정보 새로고침

  • 현장을 눌러 상세 화면을 엽니다.
  • 정보 새로고침을 누르면 승강기안전공단 자료로 모델명·검사만료일·검사결과·설치일·주소가 최신으로 바뀝니다.

🗂 기타 메뉴

📞 전화 기록

  • 회사로 걸려온 전화가 자동으로 기록됩니다. (최근 3개월)
  • 🏢 파란색 = 현장, 👷 초록색 = 직원, ❓ 빨간색 = 미등록 번호
  • 기록을 누르면 신고 접수 화면으로 이동하고, 건물명·전화번호와 접수 시간(전화 온 시간)이 자동으로 들어갑니다.

🗓️ 검사일정

  • 달력에서 날짜를 누르면 그날 검사 목록(검사종류·건물명·승강기번호·검사시간·검사자 등)이 나옵니다.
  • ◀ ▶ 버튼으로 달을 넘깁니다.

📋 준공계

  • TKE 양식 또는 대솔이엘 양식 선택
  • 현장명, 공사명, 내용, 준공일, 제출일 입력
  • + 사진철 추가로 사진 넣기 (선택)
  • 📥 PDF 다운로드

📸 공사팀 사진철

  • 교체품목, 교체호기, 파일명(현장명·품목) 입력
  • 사진 세트를 추가하고 사진을 넣습니다.
  • 📥 엑셀 다운로드 → "준공사진_현장명_품목.xlsx" 파일로 저장

💡 자주 묻는 질문

❓ 알림이 오지 않아요

  • 브라우저 알림이 허용인지 확인
  • 안드로이드: 크롬 배터리 "제한 없음" 확인 / 아이폰: 홈 화면 아이콘으로 실행했는지 확인
  • 로그아웃 후 다시 로그인하고 알림 허용
  • 🔔 알림 테스트로 정상인지 확인

❓ 알림은 오는데 소리가 안 들려요 / 진동이 안 와요

  • 휴대폰 알림 음량을 올려주세요. (미디어 음량과 따로입니다)
  • 진동은 설정 → 소리 및 진동 → "소리 모드에서 진동"을 켜야 옵니다.

❓ 담당자 목록에 이름이 안 나와요

  • 평일 주간: 인사 관리의 내 팀이 맞는지 확인하세요. (관리자에게 요청)
  • 숙직·주말·휴일: 고장 담당자 현황에서 지금 시간대 당직으로 등록했는지 확인하세요.
  • 당직은 매일 오전 8:30에 초기화됩니다.

❓ 로그인이 안 돼요

  • 아이디·비밀번호 확인
  • 관리자에게 비밀번호 초기화 요청

❓ 화면이 이상하거나 예전 화면이 보여요

  • 화면 아래 "지금 업데이트"가 보이면 눌러주세요.
  • 안 보이면 앱을 완전히 종료한 뒤 다시 실행하거나, 화면을 아래로 당겨 새로고침하세요.
  • 인터넷 연결 상태 확인
