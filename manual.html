📲 앱 설치 방법

📱 아이폰 (iOS)

  • Safari 브라우저로 앱 주소 접속
  • 하단 공유 버튼(□↑) 탭
  • "홈 화면에 추가" 선택
  • "추가" 버튼 탭 → 홈화면에 아이콘 생성
⚠️ 반드시 Safari에서 설치해야 합니다. 크롬에서는 설치 불가.

🤖 안드로이드

  • 크롬 브라우저로 앱 주소 접속
  • 주소창 우측 또는 상단에 "앱 설치" 배너 또는 메뉴(⋮) → "홈 화면에 추가" 선택
  • "설치" 버튼 탭 → 홈화면에 아이콘 생성

💻 PC (윈도우 / Mac)

  • 크롬 브라우저로 앱 주소 접속
  • 주소창 우측 설치 아이콘(⊕) 클릭 또는 메뉴(⋮) → "대솔이엘 설치"
  • "설치" 클릭 → 바탕화면 앱으로 실행 가능

🔐 로그인

  • 앱 실행 후 아이디 / 비밀번호 입력
  • 로그인 버튼 탭
  • 로그인 성공 시 메인 화면으로 이동
아이디·비밀번호는 관리자에게 문의하세요.
⚠️ 로그인 상태는 자동 유지됩니다. 공용 기기에서는 사용 후 반드시 로그아웃하세요.

🔔 알림 설정

🚨 알림을 허용해야 고장 신고 배정 및 전화 착신 알림을 받을 수 있습니다. 반드시 허용해주세요!

알림 허용 방법

  • 로그인 후 알림 허용 팝업이 뜨면 "허용" 클릭
  • 팝업이 안 뜬 경우 → 브라우저 주소창 자물쇠 아이콘 클릭 → 알림 → 허용으로 변경

🤖 안드로이드 배터리 설정 (알림 누락 방지)

  • 휴대폰 설정 앱 열기
  • 애플리케이션 → Chrome 선택
  • 배터리 탭 선택
  • 배터리 사용량을 "제한 없음"으로 변경
⚠️ 이 설정을 안 하면 화면이 꺼진 상태에서 알림이 늦게 오거나 누락될 수 있습니다.

📱 아이폰 백그라운드 설정 (알림 누락 방지)

  • 휴대폰 설정 앱 열기
  • 일반 → 백그라운드 앱 새로고침 선택
  • 목록에서 Safari를 켜짐으로 설정
⚠️ iOS는 Safari 기반 PWA만 알림을 지원합니다 (iOS 16.4 이상). 구형 기기는 알림이 지원되지 않을 수 있습니다.

📋 알림 종류

🔧 고장 신고 배정 직원
관리자·직원이 신고를 나에게 배정하면 즉시 발송됩니다. 알림을 클릭하면 해당 신고로 바로 이동하며 상태가 "배치완료"에서 "처리중"으로 전환됩니다. 확인하지 않으면 2분마다 반복 알림이 옵니다.
⚠️ 신고접수 미확인 관리자
배정된 직원이 3분 이상 신고를 확인하지 않으면 관리자에게 발송됩니다. 직원이 고장신고 알림을 확인하지 못하는 상황이므로 전화로 직접 신고내용을 전달해야 할 상황임을 알려주는 알림입니다.
🚨 피드백 미처리 직원
신고를 처리중으로 전환한 후 8시간 이상 피드백을 입력하지 않으면 발송됩니다. 현장 처리가 완료되면 반드시 피드백을 입력하고 완료 처리해주세요.
📞 전화 착신 관리자
회사 전화로 전화가 수신되면 즉시 발송됩니다. 알림 내용은 아래와 같이 표시됩니다.
① 등록된 현장 번호 → 📞 전화 착신 · [현장명]
② 등록된 직원 번호 → 📞 전화 착신 · 직원 [직급] [이름]
③ 미등록 번호 → 📞 전화 착신 · 미등록 번호 (010-XXXX-XXXX)

① 배정 알림 수신 & 확인

  • 고장 신고 배정 알림이 오면 알림을 클릭
  • 앱이 열리며 신고내역 탭으로 자동 이동
  • 해당 신고 상태가 "처리중"으로 자동 변경됨
알림을 클릭하지 않고 앱을 직접 열어도 됩니다. 신고내역 탭에서 배정된 신고를 확인하세요.

② 피드백 입력 & 완료 처리

  • 신고내역 탭에서 해당 신고 클릭
  • 현장 처리 후 피드백 내용 입력 (조치 내용, 교체 부품 등)
  • "완료 처리" 버튼 클릭
⏰ 처리중 상태에서 3분 이상 피드백을 입력하지 않으면 피드백 미처리 알림이 반복 발송됩니다.

📋 준공계 발행 공통

  • 우측 상단 ☰ 메뉴 → 준공계 탭
  • 현장명, 공사명, 내용, 날짜 입력
  • 부품 사진 추가 (선택)
  • "PDF 다운로드" 버튼 클릭 → 자동 저장

👑 관리자 기능 관리자

🔧 고장 신고 접수 & 담당자 배정

  • 우측 상단 ☰ 메뉴 → 고장 신고 탭
  • 신규 신고 내용 확인 (건물명, 호기, 고장 내용)
  • 담당자 선택 후 "배정" 버튼 클릭
  • 배정된 직원에게 자동으로 알림 발송됨

👤 계정 관리

  • 우측 상단 ☰ 메뉴 → 인사 관리 탭
  • "+ 계정 추가" 버튼 클릭
  • 아이디, 비밀번호, 역할(직원/관리자), 전화번호 입력
  • "추가" 클릭 → 계정 생성 완료
전화번호를 등록하면 해당 직원이 전화할 때 알림에 이름이 표시됩니다.

📅 휴일 관리

  • 우측 상단 ☰ 메뉴 → 휴일 관리 탭
  • 날짜 선택 후 휴일명 입력 (예: 개천절, 단체연차)
  • "추가" 버튼 클릭
등록된 휴일은 근무 배정 시 자동으로 반영됩니다.

📞 전화 착신 알림

  • 등록된 현장 전화번호 또는 직원 전화번호로 전화 수신 시
  • 관리자 PC에 "📞 전화 착신 - [현장명 또는 직원명]" 알림 표시
현장·직원 전화번호는 각각 관리현장, 인사관리에서 등록하세요.

💡 자주 묻는 질문

❓ 알림이 오지 않아요

  • 브라우저 알림이 허용 상태인지 확인
  • 휴대폰 설정 → 브라우저(크롬/Safari) → 알림 켜짐 확인
  • 앱에서 로그아웃 후 재로그인 후 알림 다시 허용

❓ 로그인이 안 돼요

  • 아이디·비밀번호 대소문자 확인
  • 관리자에게 계정 확인 요청

❓ 앱이 느리거나 안 열려요

  • 브라우저 새로고침 (당겨서 새로고침 또는 F5)
  • 앱 종료 후 재시작
  • 인터넷 연결 상태 확인
